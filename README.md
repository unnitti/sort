# 지번 정렬

클립보드에서 지번을 찾아 정렬하고, 사용하기 편한 형식으로 재가공하는 웹앱입니다.

**[앱 실행하기](https://unnitti.github.io/sort/)**

## 사용 방법

1. 지번이 포함된 텍스트를 복사합니다.
2. 앱에서 **클립보드 가져오기**를 누릅니다.
3. 결과 줄을 누르거나 키보드에서 Enter/Space를 누르면 해당 줄을 복사합니다.
4. 전체 결과는 **클립보드에 전체 복사**로 복사합니다. **내림차순** 버튼으로 정렬 방향을 바꿀 수 있습니다.

클립보드는 버튼을 눌렀을 때 읽습니다. 브라우저 권한이나 보안 정책에 따라 클립보드 읽기·쓰기가 실패할 수 있습니다.

## 처리 규칙

텍스트에서 다음 패턴을 찾아냅니다. 앞 뒤에 상품명 등 다른 문자가 있어도 패턴 부분을 추출합니다.

```text
숫자 2자리 + 영문자 2자리 + 숫자 7자리
```

앞의 숫자 두 자리는 정렬과 출력에서 무시합니다. 영문은 대소문자를 구분하지 않고 결과에서는 대문자로 표시합니다. 예를 들어 `55ZB0788009`은 `ZB7-88-009`로 바뀝니다. 형식에 맞지 않는 내용은 제외하고 제외 항목 수를 알립니다.

영문 두 자리를 먼저 알파벳순으로 정렬하고, 같은 영문 안에서는 뒤의 일곱 자리를 숫자 값으로 정렬합니다. 기본은 오름차순이며, 내림차순은 전체 순서를 역순으로 바꿉니다.

## 오프라인 사용 및 업데이트

- 처음에는 인터넷에 연결된 상태에서 앱을 열어 주세요. 앱 파일은 브라우저에 캐시되므로, 이후에는 인터넷 연결이 불안정하거나 끊긴 상황에서도 사용할 수 있습니다.
- 앱을 업데이트할 때는 인터넷에 연결한 상태에서 앱을 다시 열어 주세요. 새 버전의 파일을 내려받아 적용합니다.
- 앱 파일을 변경해 배포할 때는 `sw.js`의 캐시 버전도 함께 올려야 합니다. 버전이 바뀌면 새 파일을 캐시에 준비한 뒤 이전 캐시를 교체합니다.
- 브라우저의 웹사이트 데이터나 캐시를 삭제한 경우에는 인터넷에 연결해 앱을 다시 열어야 합니다.

## 지원 환경

iPhone Safari의 홈 화면에 추가한 웹앱을 기준으로 확인했습니다. Safari 탭, Android 및 다른 브라우저에서의 동작은 별도 확인이 필요합니다.

## 유지보수 메모

- 이 앱은 지정된 형식만 처리하는 도구입니다. 다른 형식은 결과에서 빠집니다.
- 기존 정렬 기준과 출력 형식은 업무 흐름에 영향을 주므로 변경 전후에 실제 입력 예시로 확인합니다.
- 기능을 수정할 때는 온라인 실행, 오프라인 재실행, 주요 기능을 함께 점검합니다.
